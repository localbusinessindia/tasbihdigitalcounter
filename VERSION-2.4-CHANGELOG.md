# Version 2.4 changelog

## Audio / voice guide
- Added a shared, optional browser text-to-speech guide for Arabic phrases.
- Added slow/normal/fast rate choices and a stop control.
- Added compact listen controls beside the Arabic entries on the 99 Names page.
- Clearly labels device TTS as a pronunciation aid, not a recorded Qur’anic recitation or tajwid instruction. Device/browser voice availability and pronunciation quality vary.

## Content-to-counter integration
- Added contextual counter launch cards to the main Dhikr guide pages.
- Added direct links for phrase-specific counter presets and the after-salah / bedtime guided routines.
- Added a no-target 99 Names study-session counter; it does not prescribe repetition counts for the Names.
- Bedtime URL variants now correctly select the requested 34-33-33 or 33-33-34 order.

## Technical
- Added `voice-guide.js`, lightweight CSS, and bumped the service-worker cache to v11.
- Existing page URLs and stored counter data are preserved.

## Limitations / verification
- This version does not include recorded MP3 recitations. Browser TTS is generated by the user's device and may not have an Arabic voice installed.
- Religious content and translations have not been independently reviewed by a qualified scholar.
- Run the full audit and test audio on physical Android/iOS devices after deployment.
