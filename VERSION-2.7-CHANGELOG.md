# Version 2.7 changelog

- Replaced the non-functional placeholder email with a real public feedback route to the project's GitHub Issues page. The page warns visitors that issue reports are public.
- Added an actual downloadable PDF for the existing 99 Names table, retaining a separate browser print option. The PDF is based on the page's 99 Arabic entries, transliterations and English glosses and preserves the note that scholarly enumerations and translations vary.
- Added the PDF to the service-worker precache and bumped the cache name to v14.
- Expanded the practical beginner, digital-vs-physical and daily-habit guides with original guidance on local backups, device alerts, trade-offs and routine maintenance.
- Clarified that the current voice fallback is device text-to-speech, not a verified recitation recording.
- Updated deployment instructions and audit notes to distinguish completed code changes from owner/specialist checks still outstanding.

## Still not included / not independently verified
- No authentic MP3 recitations are included; only verified recordings with documented permission/licensing and attribution may be added.
- No native speaker has independently proofread all translations.
- Religious wording, meanings, hadith references and routine selections still require qualified review.
- Vibration/audio output, offline use and PDF opening need physical-device testing.
- Live Netlify response headers, external links, Lighthouse/CrUX and Search Console indexing have not been tested by this package build.
